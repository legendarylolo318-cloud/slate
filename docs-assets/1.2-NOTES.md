## Decisions
* MCP is now a stateful Streamable-HTTP session (same URL and loopback / Host protections) so that
  the client name and subscriptions work.
* Dormancy: the MCP, party and DJ hooks begin with one atomic check; a source-guard test enforces it
  for the MCP hooks. Party state lives in statics created at start and cleared at end.
* The MCP play log for `get_listening_stats` is only written while the server runs.
* The existing MCP `create_playlist` still makes PUBLIC playlists; new tools create UNLISTED ones.
